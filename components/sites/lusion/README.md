# Lusion Site Components

Isolated components reverse-engineered from [https://lusion.co/](https://lusion.co/).

## Structure
- `LusionPage.tsx`: Main page layout and section orchestration
- `Header.tsx`: Navigation bar with SVG wordmark, audio equalizer indicator, CTA pill, and menu toggle
- `MenuOverlay.tsx`: Fullscreen responsive modal navigation with smooth section scrolling
- `HeroCanvas.tsx`: Interactive Three.js 3D WebGL scene with glossy metallic geometric cluster, mouse-driven inertia, orbiting nodes, and drifting particle field
- `Hero.tsx`: Dynamic 0-100% preloader badge and typographic headline
- `IntroSection.tsx`: Multidisciplinary studio capabilities and craft pillars
- `PlayReel.tsx`: Interactive studio showreel player
- `ProjectGallery.tsx`: Categorized portfolio with filters (`All`, `3D`, `WebGL`, `Motion`, `AI`) and hover interaction
- `PhilosophySection.tsx`: Studio manifesto and awards counter
- `Footer.tsx`: Large CTA, direct email connection, studio coordinates, and social channels
- `lusion.module.css`: Scoped CSS Module ensuring zero leakage into 13 Utopia production styles
